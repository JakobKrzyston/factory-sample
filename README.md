# factory-sample

A deliberately small TypeScript library that [factory-platform](https://github.com/JakobKrzyston/factory-platform) runs its agents against. Its issues are the factory's practice work; its pull requests are opened by an unattended agent and merged, or not, by a person.

```sh
node --test   # or: npm test
```

Needs Node 22.18 or later, which runs TypeScript directly. There are no dependencies.
